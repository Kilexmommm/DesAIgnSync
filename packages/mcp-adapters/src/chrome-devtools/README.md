# packages/mcp-adapters/src/chrome-devtools/README.md

Adapter over the Chrome DevTools MCP: page listing/selection, accessibility snapshot, computed
styles, controlled JS evaluation, geometry and screenshots. It discovers capabilities and maps
them to internal operations, so the core is never coupled to concrete MCP tool names.

- **Owner:** Agent 3 - MCP Integrations
- **Waves:** Wave 2 (DS-005), Wave 3 (DS-010/DS-012 evidence capture)
- **Status:** placeholder - no implementation yet (Wave 1 only establishes the skeleton).

Sources of truth: `docs/AI_Design_System_Compliance_MCP_Spec_v2.1.md (section 10)` and `docs/backlog/DS-005.md`.
