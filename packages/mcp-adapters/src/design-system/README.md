# packages/mcp-adapters/src/design-system/README.md

Generic Design System MCP adapter: normalizes components, variants, props, docs, tokens and
visual references from ANY Design System MCP into `ComponentSignature`, mapping each server own
tools to the logical operations (list_components, get_component, search_components,
get_variant_reference, get_usage_guidelines). Missing data stays missing.

- **Owner:** Agent 3 - MCP Integrations
- **Waves:** Wave 2-3 (DS-006, DS-013)
- **Status:** placeholder - no implementation yet (Wave 1 only establishes the skeleton).

Sources of truth: `docs/AI_Design_System_Compliance_MCP_Spec_v2.1.md (section 11)` and `docs/backlog/DS-006.md`.
