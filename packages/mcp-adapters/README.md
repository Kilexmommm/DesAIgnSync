# @desaignsync/mcp-adapters

Adapters que traducen MCPs crudos (Chrome DevTools, Design System, Storybook)
a operaciones internas (`listComponents`, `getVariant`, `getTokens`, …) por
descubrimiento de capabilities, con namespacing. Storybook es un preset del
adapter de Design System, no una URL obligatoria.

Ver `docs/adr/ADR-003-*`, `ADR-004-*` y `docs/backlog/DS-004.md`, `DS-005.md`.
