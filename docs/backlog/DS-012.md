# DS-012 [Element Picker] Implementar selección focalizada de elementos para revisión

Fuente: https://github.com/Kilexmommm/DesAIgnSync/issues/12

---

## Objetivo
Permitir que el usuario identifique un elemento concreto de la página actual y lo convierta en el foco de una revisión de Design System.

## Historia de usuario
Como diseñador, QA o desarrollador, quiero seleccionar un elemento visible para obtener su evidencia estructural y compararlo con el componente de referencia.

## Prioridad
P0

## Alcance
- Acción `Select element` desde el Side Panel.
- Estado temporal de selección visual.
- Cancelación mediante Escape o acción explícita.
- Resolución del elemento seleccionado a `ElementEvidence`.
- Resumen en el Side Panel con tag, role, accessible name/text y clases relevantes.
- Invalidar selección cuando cambia el documento o deja de ser válida.

## Criterios de aceptación
- [ ] El usuario puede seleccionar un elemento visible de la página activa.
- [ ] El estado visual de selección es temporal y desaparece al finalizar.
- [ ] No se realizan cambios persistentes en la aplicación inspeccionada.
- [ ] La selección se transforma al esquema definido en DS-010.
- [ ] El Side Panel muestra tag/role/label del elemento seleccionado.
- [ ] Una selección obsoleta se invalida de forma segura.
- [ ] Se prueban elementos nativos button/input/link y elementos con role ARIA.
- [ ] Limitaciones de iframe o shadow DOM no accesible se muestran claramente.
