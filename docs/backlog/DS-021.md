# DS-021 [Ask AI] Añadir chat contextual sobre el elemento o reporte seleccionado

Fuente: https://github.com/Kilexmommm/DesAIgnSync/issues/21

---

## Objetivo
Permitir preguntas posteriores usando la misma evidencia y referencias ya obtenidas, sin rehacer todo el análisis ni perder trazabilidad.

## Historia de usuario
Como revisor, quiero preguntar cosas como `¿por qué no cumple?`, `¿debería ser Primary o Secondary?` o `¿qué componente del DS sería más apropiado?` sobre el elemento seleccionado.

## Prioridad
P1

## Alcance
- Campo `Ask AI` en el Side Panel.
- Contexto limitado al análisis activo y fuentes autorizadas.
- Acciones rápidas:
  - Explain finding.
  - Compare with Storybook/Design System.
  - Suggest component.
  - Validate accessibility.
  - Explain confidence.
- Reusar evidence, candidates, signatures y deterministic findings.
- No permitir que la respuesta sobrescriba el reporte original.

## Criterios de aceptación
- [ ] Una pregunta usa el contexto del elemento/reporte activo sin requerir reenviar DOM completo.
- [ ] La respuesta distingue hechos de recomendación.
- [ ] Puede citar el componente/variante y findings usados como contexto.
- [ ] Si la pregunta requiere evidencia no disponible, lo indica y puede solicitar una nueva captura controlada.
- [ ] Cambiar de selección inicia un contexto nuevo o pide confirmación para conservar el anterior.
- [ ] El contenido de la página continúa tratándose como evidencia no confiable.
- [ ] Historial de chat no incluye API keys ni secretos.
