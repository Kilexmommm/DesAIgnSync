# DS-006 [Design System MCP] Crear adaptador genérico para MCP de Design System

Fuente: https://github.com/Kilexmommm/DesAIgnSync/issues/6

---

## Objetivo
Definir una interfaz estable para consultar componentes, variantes, propiedades, documentación y referencias visuales desde cualquier MCP de Design System.

## Historia de usuario
Como usuario, quiero conectar el MCP de mi Design System para que DesAIgnSync use esa fuente como referencia oficial al validar una implementación.

## Prioridad
P0

## Contrato interno esperado
El adaptador debe poder resolver, cuando el MCP lo permita:
- listar componentes;
- buscar componente por nombre/semántica;
- obtener variantes/stories;
- obtener props/args;
- obtener documentación;
- obtener tokens/referencias de estilos;
- obtener screenshot o referencia visual;
- consultar un componente concreto.

## Requerimientos
- Mapeo de tools MCP reales a una interfaz interna común.
- Capability detection: no asumir que todos los MCP exponen las mismas tools.
- Cache local opcional de metadata, invalidable.
- Identificar fuente y timestamp de cada referencia.
- No fabricar datos faltantes.

## Criterios de aceptación
- [ ] Se puede configurar un MCP como `Design System Source`.
- [ ] La conexión descubre capacidades disponibles.
- [ ] Se puede obtener una lista normalizada de componentes.
- [ ] Se puede consultar un componente y sus variantes cuando el MCP lo soporte.
- [ ] Cada dato devuelto conserva referencia a la fuente MCP/tool.
- [ ] Campos no disponibles quedan explícitamente como `unknown/not_available`.
- [ ] El core de matching consume la interfaz interna y no depende de Storybook directamente.

## Dependencias
- DS-004

## Nota
Storybook será un preset importante, pero no debe ser la única fuente compatible.
