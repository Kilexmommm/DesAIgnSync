# DS-017 [Profiles] Crear modos Simple, Advanced y Expert con perfiles de validación

Fuente: https://github.com/Kilexmommm/DesAIgnSync/issues/17

---

## Objetivo
Permitir configurar qué revisar y con qué tolerancias sin obligar a todos los usuarios a escribir prompts.

## Historia de usuario
Como usuario, quiero elegir un nivel de configuración acorde a mi experiencia y guardar perfiles reutilizables por proyecto.

## Prioridad
P0

## Modos
### Simple
Checks on/off para:
- Storybook/Design System match;
- Colors;
- Typography;
- Spacing;
- Border radius;
- Dimensions;
- Accessibility;
- Content;
- Responsive/otros futuros.

### Advanced
Todo lo anterior + tolerancias, severidades y `Advanced Validation Prompt`.

### Expert
Todo lo anterior + pesos de matching, top N candidates, minimum confidence, proveedor/modelo, parámetros LLM seguros y opciones avanzadas soportadas.

## Perfiles iniciales
- Design QA.
- Design System Compliance.
- Accessibility.
- Forms Review.
- DS Migration.
- Custom.

## Criterios de aceptación
- [ ] Cambiar checks actualiza la configuración estructurada sin editar manualmente el prompt.
- [ ] El usuario puede guardar, duplicar, renombrar y eliminar perfiles custom.
- [ ] Un perfil conserva reglas, tolerancias y prompt avanzado.
- [ ] Los perfiles no guardan API keys.
- [ ] Simple oculta parámetros técnicos innecesarios.
- [ ] Expert permite modificar pesos sin aceptar valores inválidos.
- [ ] Existe `Reset to defaults` por perfil.
- [ ] El reporte registra qué perfil/configuración produjo el análisis.
