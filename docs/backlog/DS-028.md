# DS-028 [Settings UI] Crear pantalla unificada de configuración MCP, LLM y validación

Fuente: https://github.com/Kilexmommm/DesAIgnSync/issues/28

---

## Objetivo
Centralizar la configuración del producto en una UI clara para que el usuario no tenga que editar archivos manualmente.

## Historia de usuario
Como usuario avanzado, quiero administrar mis MCP, proveedor LLM y perfiles de validación desde el Side Panel o una vista de Settings dedicada.

## Prioridad
P0

## Secciones
### Connections
- Local Host status.
- Chrome DevTools MCP.
- Design System MCP.
- Storybook MCP preset.
- MCP custom.

### AI Provider
- Provider Name.
- Base URL.
- API key (masked).
- Fetch Models.
- Add Model Manually.
- Selected Model.
- Vision Auto/Yes/No.
- Custom Headers.
- Test Connection.

### Validation
- Simple / Advanced / Expert.
- Rules/checks.
- Tolerances.
- Advanced Validation Prompt.
- Matching weights en Expert.

### Privacy
- screenshots on/off;
- redaction;
- retention;
- deterministic-only mode.

## Criterios de aceptación
- [ ] Settings puede abrirse sin abandonar la página revisada.
- [ ] Los secretos se muestran enmascarados y se guardan mediante DS-009.
- [ ] Cada conexión tiene estado y `Test connection`.
- [ ] Cambios inválidos no sustituyen una configuración previamente válida.
- [ ] Se puede exportar configuración no sensible.
- [ ] Se puede importar configuración no sensible con validación de esquema.
- [ ] El usuario puede restaurar defaults por sección.
- [ ] La UI diferencia claramente MCP source, LLM provider y Validation Profile.
