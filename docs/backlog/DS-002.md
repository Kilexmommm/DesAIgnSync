# DS-002 [Extension] Crear extensión Chrome Manifest V3 con Side Panel

Fuente: https://github.com/Kilexmommm/DesAIgnSync/issues/2

---

## Objetivo
Crear la aplicación Chrome que funcionará como interfaz de DesAIgnSync sin modificar la aplicación inspeccionada.

## Historia de usuario
Como diseñador, QA o desarrollador, quiero abrir DesAIgnSync en el Side Panel de Chrome para revisar la página actual sin abandonar mi contexto de trabajo.

## Prioridad
P0

## Alcance
- Manifest V3.
- `chrome.sidePanel` como superficie principal.
- Service worker/background mínimo.
- Permisos mínimos necesarios.
- Estado de conexión con Local MCP Host.
- Detectar pestaña activa y contexto básico: URL, título, tabId y windowId.
- UI React + TypeScript.
- Estados: desconectado, conectando, listo, error.

## Criterios de aceptación
- [ ] La extensión puede cargarse con `Load unpacked` sin errores.
- [ ] El icono de la extensión permite abrir el Side Panel.
- [ ] El Side Panel permanece funcional al cambiar de pestaña.
- [ ] Muestra URL/título de la pestaña activa sin modificar su DOM.
- [ ] La extensión no ejecuta procesos locales ni `npx` directamente.
- [ ] La UI incluye indicador de estado del Local MCP Host.
- [ ] No se solicitan permisos Chrome que no sean necesarios.
- [ ] Build de producción genera un paquete instalable de la extensión.

## Dependencias
- DS-001

## Notas técnicas
El Side Panel es cliente del Local MCP Host. Los servidores MCP `stdio` no deben ejecutarse dentro de la extensión.
