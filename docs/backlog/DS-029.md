# DS-029 [Persistence] Guardar historial local de revisiones y exportar reportes

Fuente: https://github.com/Kilexmommm/DesAIgnSync/issues/29

---

## Objetivo
Permitir comparar revisiones y compartir resultados sin almacenar datos de forma indefinida ni enviar contenido a un backend central.

## Historia de usuario
Como revisor, quiero guardar localmente los resultados relevantes y exportarlos para seguimiento, documentación o creación de tareas.

## Prioridad
P1

## Alcance
- Historial local opcional de análisis.
- Metadata: URL/host, fecha, perfil, modelo, Design System source, summary y findings.
- Configuración de retención: disabled / N últimas / N días.
- Borrado individual y total.
- Export formats iniciales: JSON estructurado y Markdown legible.
- Export debe excluir secretos y configuración sensible.
- Screenshots opcionales según política de privacidad.
- Identificador de análisis para trazabilidad.

## Criterios de aceptación
- [ ] El usuario puede desactivar por completo el historial.
- [ ] El historial respeta la política de retención configurada.
- [ ] Se puede reabrir un reporte histórico sin volver a ejecutar el análisis.
- [ ] El reporte histórico identifica que la evidencia corresponde a una captura pasada.
- [ ] Export JSON valida contra un schema versionado.
- [ ] Export Markdown incluye checklist y fuentes sin API keys.
- [ ] `Delete all history` elimina datos locales asociados, incluidas imágenes retenidas.
- [ ] No existe sincronización cloud implícita.
