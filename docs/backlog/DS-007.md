# DS-007 [Storybook MCP] Añadir preset de integración para Storybook MCP

Fuente: https://github.com/Kilexmommm/DesAIgnSync/issues/7

---

## Objetivo
Facilitar la conexión de un Storybook que exponga MCP, mapeando sus herramientas al contrato genérico de Design System.

## Historia de usuario
Como equipo que usa Storybook, quiero conectarlo a DesAIgnSync sin configurar manualmente cada tool para usar componentes y stories como referencia de validación.

## Prioridad
P0

## Alcance
- Preset `Storybook MCP` sobre DS-006.
- Configuración por endpoint MCP o definición local soportada.
- Mapeo de herramientas equivalentes a:
  - listar documentación/componentes;
  - consultar componente;
  - consultar story/variante;
  - recuperar metadata/args/props disponible.
- Capability detection por versión.
- Estado visible de conexión y última sincronización.

## Criterios de aceptación
- [ ] El usuario puede elegir `Storybook MCP` como tipo de fuente.
- [ ] `Test connection` valida el endpoint/servidor y muestra tools encontradas.
- [ ] Los componentes se devuelven en el modelo normalizado de DS-006.
- [ ] Variantes/stories quedan relacionadas con su componente padre.
- [ ] Si Storybook no expone una capability, el sistema no la simula.
- [ ] La integración puede volver a sincronizar sin reiniciar la extensión.
- [ ] Errores de compatibilidad indican claramente la tool/capability faltante.

## Dependencias
- DS-004
- DS-006

## Fuera de alcance
Crawler de Storybook por URL como mecanismo principal. MCP es la vía preferida.
